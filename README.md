# FunTime — фан-сайт сервера

Одностраничный неофициальный сайт про анархический сервер **FunTime** (`mc.funtime.su`):
что это за проект, как зайти, что делать в первую ночь и как не потерять базу.

Сделан без сборки и зависимостей: чистые HTML + CSS + JS, работает из файла.

## Как открыть

- Двойной клик по `index.html` — откроется в браузере.
- Либо локальный сервер (нужен только если хочется проверить `navigator.clipboard` в «правильном» origin):

```powershell
python -m http.server 8080
# затем http://localhost:8080
```

## Куда выложить, чтобы видели другие

Пошагово — в [GITHUB.md](GITHUB.md). Коротко: публичный репозиторий → Settings → Pages →
ветка `main`, папка `/ (root)`. Если установлены `git` и `gh`, то же самое делает
`deploy.ps1` одной командой.

## Структура

```
index.html            разметка и весь текст
css/style.css         тема, сетки, адаптив, анимации
js/app.js             меню, копирование IP, скролл-спай, аккордеоны, лайтбокс, reveal
assets/hero.png       фон первого экрана (пиксель-арт, 1920x1080)
assets/og.png         превью для соцсетей (1200x630)
assets/preview.png    скриншот первого экрана
assets/favicon.png    блок травы вместо иконки
assets/icons/*.png    иконки для карточек (64x64)
assets/gallery/*.png  6 иллюстраций для галереи (1440x810)
tools/gen_assets.py   генератор фона, иконок и фавиконки (Pillow)
tools/gen_scenes.py   генератор иллюстраций для галереи (Pillow)
```

Графика генерируется кодом, поэтому её легко перекрасить: поправь палитру
(`GRASS`, `DIRT`, `STONE`) или композицию в `hero()` / сценках и пересобери:

```powershell
python tools/gen_assets.py
python tools/gen_scenes.py
```

Картинки в галерее — иллюстрации в стиле игры, а не скриншоты с сервера:
реальные базы игроков выглядят иначе, и скриншотов у фан-сайта нет.

## Что легко поменять

| Что | Где |
| --- | --- |
| IP и порт | `index.html`: `data-copy="mc.funtime.su"`, блок `.ipcard`, футер |
| Версии игры | подпись «1.8 – 1.21» в hero-статах, шагах и FAQ |
| Режимы/механики | карточки внутри `<section id="modes">` |
| Галерея | `<figure class="shot">` в `<section id="gallery">` + сценки в `tools/gen_scenes.py` |
| Гайды | блоки `<details class="guide">` в `<section id="guides">` |
| Вопросы | `<details class="faq__item">` в `<section id="faq">` |
| Цвета | `:root` в `css/style.css` (`--green`, `--bg`, `--panel`) |

## Про содержание

Сервер **не делится на отдельные режимы** — весь проект про анархию. Тексты на
сайте это отражают: раздел «Что тебя ждёт» описывает стороны анархии (рейды, базы,
экономику), а не разные режимы.

Данные об IP, версиях и онлайне взяты из открытых мониторингов и могут устареть —
если что-то поменялось, правится в одном-двух местах (см. таблицу выше).

Сайт не публикует эксплойты, дюпы и схемы обхода правил: это ломает экономику
сервера и заканчивается баном.
